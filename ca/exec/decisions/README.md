# Registre des Décisions Exécutives Déléguées (EXEC)

Ce dossier archive les décisions de gestion courante adoptées par le Comité exécutif et les officiers de **COHABITAT.CC**.

---

## Convention de nommage

```text
ca/exec/decisions/YYYY-MM-DD-EXEC-XX-nom-court-en-kebab-case.md
```
- `YYYY-MM-DD` : Date de la décision.
- `EXEC-XX` : Numéro séquentiel annuel de la décision exécutive (ex. `EXEC-01`, `EXEC-02`).
- `nom-court` : Résumé en quelques mots (ex. `2026-10-20-EXEC-01-mandat-etude-zonage-villeray.md`).

---

## Modèle type
Pour créer une nouvelle décision, copiez le fichier [`2026-00-modele-decision-exec.md`](2026-00-modele-decision-exec.md).
